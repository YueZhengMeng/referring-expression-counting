### 说明

### 模型结构

所有模型的主实验 image backbone 均为 Swin-T，同时 CAD-GD、W2-Net 和 C-REX 的论文还报告了 Swin-B 配置的性能。

文本编码器在不同论文中有时只写作 BERT 或 Bert-base，根据常见配置推测均为 `bert-base-uncased`。

C-REX 是训练阶段的可插拔模块，不改变宿主模型的结构。

### 训练目标与匹配机制

GroundingDINO 使用边界框检测式目标，使用基于预测框重叠度的 GIoU Cost 和 GIoU Loss。  
GroundingREC 将边界框预测改为点预测，因此不再使用 GIoU 项；其匹配和训练定位项均基于点坐标的 L1 距离。  
DCount 和 CAD-GD 的论文正文并未完整报告其匹配代价细节，推测与 GroundingREC 一致。

| 方法          | Hungarian cost                                                                 | Train Loss                                                                      | 新增或改进目标                                                                                                                                                                                                                   |
|:--------------|:-------------------------------------------------------------------------------|:--------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GroundingDINO | Classification Cost、L1 Localization Cost 和 GIoU Cost                         | Classification Loss、L1 Localization Loss 和 GIoU Loss                          | GIoU Cost 与 GIoU Loss 用于边界框监督                                                                                                                                                                                            |
| GroundingREC  | Classification Cost、L1 Localization Cost                                      | Classification Loss、L1 Localization Loss 和 Contrastive Loss                   | 图文对比损失：当前query匹配的GT点对应的caption为正样本，其他的caption为负样本                                                                                                                                                    |
| CAD-GD        | 未报告，推测与 GroundingREC 一致                                               | Classification Loss、L1 Localization Loss 和 Contrastive Loss、**Density Loss** | Density Loss: CAD Generation Module 预测的概率密度图与真实概率密度图的L2损失                                                                                                                                                     |
| DCount        | 语义置信度 Cost(与 Classification Cost 在数学逻辑上一致)、L1 Localization Cost | Classification Loss、L1 Localization Loss 和 **Contrastive Loss(attr)**         | Classification Loss 为 focal loss；Contrastive Loss 为使用 Attribute Semantic discrimination 难负样本挖掘后，t2i与i2t双向对比损失的平均值。                                                                                      |
| W2-Net        | Classification Cost、L1 Localization Cost 和 **Repulsive Cost**                | Classification Loss、L1 Localization Loss                                       | Classification Loss 为 focal loss；Repulsive Cost: 提高预测点与其他子类的GT点的匹配成本，减少模糊匹配；**没有 Contrastive Loss**。                                                                                               |
| C-REX         | -                                                                              | -（**提出在视觉空间进行的改进监督对比学习**）                                   | 通过二分图匹配、与当前caption对应的GT点匹配成功的视觉 token。同图像中其余 token 作为负样本；仅以正样本 token 作为 anchor，负样本之间不进行相互聚合；GroundingREC/CAD-GD 中替换原图文对比损失，GroundingDINO 中作为额外损失加入。 |
